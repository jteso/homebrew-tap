# Homebrew tap

Install the Luminatti CLI (formula):

```sh
brew install jteso/tap/luminatti-cli
```

The CLI is released from [jteso/luminatti-cli](https://github.com/jteso/luminatti-cli).

Install the Luminatti macOS app:

```sh
brew install --cask jteso/tap/luminatti
```

The app cask is released from [jteso/luminatti](https://github.com/jteso/luminatti). Homebrew opens **Luminatti** after installation. Choose a repository when prompted. To build the desktop app from source, see the [Luminatti README](https://github.com/jteso/luminatti#install-from-source).
